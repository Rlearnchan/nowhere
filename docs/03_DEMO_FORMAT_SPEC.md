# Demo Format Specification

## 1. 기본 규격

- 이름: `NOWHERE NOON BRIEF`
- 기본 분량: A4 세로 4페이지
- 허용 범위: 3-5페이지
- 기준 시각: 페이지 상단에 KST로 표시
- 읽는 시간: 5분 이내
- 기본 대상: 진행자·프로듀서·사내 의사결정자
- 공개 성격: 투자 권유가 아닌 시황 참고자료

## 2. 페이지 구성

### Page 1 - 오늘 장 한눈에

목표:

- 20초 안에 시장 상태를 이해하게 한다.

필수 요소:

- 편집 제목
- 한 줄 시장 요약
- KOSPI·KOSDAQ 큰 숫자
- 장중 저점 대비 회복률
- 상승·하락 종목 수
- USD/KRW
- 전일 미국시장 핵심 3-4개
- 시장 불릿 최대 5개

정보 예산:

```text
제목          1개
한 줄 요약     1개
대형 숫자      4-6개
불릿           최대 5개
```

### Page 2 - 한국시장 구조

목표:

- 지수 상승·하락이 시장 전체의 움직임인지, 일부 대형주의 움직임인지 보여준다.

필수 요소:

- KOSPI·KOSDAQ day range
- 시장 폭
- 외국인·기관·개인 수급
- 프로그램 수급
- 대표 종목 8-10개
- 해석 문장 3개

권장 차트:

- 범위 바: 저가-고가 안에서 시가·현재가 위치
- 시장 폭 bar
- 수급 diverging bar
- 시총 상위 종목 heat tiles

### Page 3 - 핵심 뉴스와 오후 촉매

목표:

- 기사 수가 아니라 오늘 시장과 관계있는 사건을 보여준다.

필수 요소:

- 사건 단위 뉴스 5-8개
- 각 사건의 시장 연결
- 오늘 남은 일정
- 공식 공시 또는 정책 이벤트

기본 문법:

```text
무슨 일이 있었나
-> 왜 오늘 시장과 관계가 있나
-> 어떤 자산·업종에 연결되는가
```

### Page 4 - 핵심 스토리

목표:

- 오늘 시장의 가장 중요한 질문 하나를 2-3단락으로 설명한다.

고정 구조:

1. 확인된 사실
2. 가장 설명력 있는 해석
3. 반론과 판단 변경 조건

측면 박스:

- 근거 3-5개
- 반대 증거 1-2개
- 진행자 질문 1-2개

### Page 5 - 선택적 두 번째 스토리/진행자 큐

다음 중 하나일 때만 사용한다.

- 급락·급등의 원인이 복합적일 때
- 정책 발표 또는 기업 실적이 큰 비중을 차지할 때
- 오후 이벤트가 시장 체제를 바꿀 가능성이 클 때

구성:

- 두 번째 스토리 2-3단락
- 이벤트 타임라인
- 진행자 질문 3개
- 오후 체크포인트

## 3. 3페이지 변형

조용한 날:

```text
1. 오늘 장 한눈에
2. 한국시장 구조
3. 뉴스 + 짧은 스토리 + 진행자 큐
```

억지로 심층 소재를 만들지 않는다.

## 4. 5페이지 변형

급변일:

```text
1. 오늘 장 한눈에
2. 한국시장 구조
3. 핵심 뉴스·촉매
4. 시장 전체 스토리
5. 업종·정책·기업 심층 스토리
```

## 5. 편집 규칙

### 제목

좋은 제목:

- `지수는 복원됐지만, 시장은 아직 복구되지 않았다`
- `환율은 진정됐지만 외국인 매수는 아직 좁다`
- `실적은 강한데 주가는 왜 흔들리는가`

피할 제목:

- `오늘의 시황`
- `코스피 상승`
- `주요 뉴스 정리`

### 한 줄 요약

- 90자 안팎
- 방향 + 구조 + 핵심 조건을 포함
- 뉴스 제목을 반복하지 않음

### 뉴스 불릿

- 최대 2문장
- 숫자·기관·종목을 구체적으로 씀
- 중요하지 않은 기사로 개수를 채우지 않음

### 심층 스토리

- 450-750자
- 문단 3개 이내
- 반드시 반론 또는 조건을 포함
- 확정되지 않은 원인은 `가능성`, `해석`, `후보`로 표현

### 진행자 질문

답이 이미 정해진 질문보다, 판단의 경계를 드러내는 질문을 쓴다.

좋은 예:

- `지수가 반등했다는 것과 시장이 안정됐다는 것은 같은 의미인가요?`
- `레버리지 ETF는 원인인가요, 이미 약해진 시장을 키운 증폭기인가요?`
- `ASML의 어떤 표현이 한국 반도체에 더 중요합니까?`

## 6. 시각 규칙

### 독자적 스타일

참고자료의 정보 구조는 활용하되 로고, 장식, 색상, 표 모양을 복제하지 않는다.

권장 팔레트:

```text
Deep Navy     #0B1F33
Slate         #263A4D
Teal          #00A6A6
Positive      #D9534F  (한국식 상승 표시)
Negative      #3B73B9
Gold          #D8A63C
Paper         #F4F6F8
Ink           #17212B
```

상승·하락 색은 국내 독자의 관습을 따르되, 텍스트 기호 `+/-`를 함께 표시해 색에만 의존하지 않는다.

### 폰트

- 제목: NanumSquare Bold
- 본문: Noto Sans CJK KR 또는 NanumSquare
- 숫자: NanumSquare Bold

### 밀도

- 페이지당 핵심 메시지 1개
- 표는 최대 3개
- 차트는 최대 4개
- 본문 최소 10pt 상당
- 출처 최소 7pt 상당

## 8. 데모 품질 기준

고점의 데모는 다음을 만족해야 한다.

- 숫자가 많지만 첫 시선이 어디로 가야 하는지 명확함
- KOSPI와 KOSDAQ의 다른 상태를 시각적으로 보여줌
- 뉴스가 기사 제목 모음이 아니라 사건 구조로 정리됨
- 한 개 이상의 스토리가 사실·해석·반론·조건 구조를 가짐
- 진행자가 그대로 읽거나 질문으로 전환할 수 있음
- 출처와 데이터 한계가 숨겨지지 않음
- 5페이지를 넘기지 않음

## 9. Demo 2026-07-14 편집 의도

제목:

> 지수는 복원됐지만, 시장은 아직 복구되지 않았다

핵심 대비:

```text
KOSPI +1.61% / 장중 저점 대비 +7.3%
vs
KOSPI 상승 종목 비율 약 31%
KOSDAQ -2.08% / 상승 종목 비율 약 25%
```

첫 번째 스토리:

- 반도체 대형주와 기관·프로그램 매수가 만든 좁은 지수 복원
- 코스닥 사이드카와 시장 폭은 여전히 약한 위험선호를 시사

두 번째 스토리:

- SK하이닉스 단기 실적 기대치 하향과 HBM 구조적 강세의 충돌
- ASML·TSMC가 업황 판단의 다음 확인점
- 레버리지 ETF는 근본 원인보다 변동성 증폭기로 해석
